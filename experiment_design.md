# Дизайн A/B-теста SMS-рассылки

Проверяю, повышает ли SMS вероятность покупки и есть ли основания для дальнейшей рассылки. Это учебный разбор завершённого эксперимента на открытых данных [X5 RetailHero](https://ods.ai/competitions/x5-retailhero-uplift-modeling/data).

Для анализа использую `uplift_train.csv.gz`: `client_id` — клиент, `treatment_flg` — назначенная группа, `target` — факт покупки. Исходный период покупки в файле не указан.

## Метрика и гипотезы

A — контроль без исследуемой SMS, B — группа SMS. Единица рандомизации и анализа — клиент. Конверсия равна числу покупателей среди всех клиентов группы; несколько покупок одного клиента дают один бинарный исход.

| Параметр | Значение |
|---|---|
| Группы | A: treatment_flg=0; B: treatment_flg=1 |
| Основная метрика | Клиенты с target=1 / все клиенты группы |
| Эффект | 100×(pB−pA), в процентных пунктах |
| H0 | pB≤pA |
| H1 | pB>pA |
| Критерий | Односторонний pooled z-тест двух независимых пропорций |
| Alpha | 0.05 |
| Мощность | 80%; сравнение с 90% |
| Плановое распределение | 50/50 |
| Базовая конверсия p0 | 0.50; дополнительные сценарии 0.30 и 0.70 |
| Плановый эффект MDE | +1 п.п.; дополнительные сценарии +0.5 и +2 п.п. |

Параметры планирования выбраны до расчёта фактических конверсий. p0=0.5 — сценарий с максимальной дисперсией Бернулли; эффект 1 п.п. в расчётах соответствует delta=0.01. MDE задаёт чувствительность теста; порог окупаемости зависит от расходов и маржи.

## Выборка и симуляции

Размер группы рассчитываю через положительный Cohen’s h: `proportion_effectsize(p0+delta, p0)` и `NormalIndPower.solve_power` с `alternative="larger"`, `ratio=1`. Результат округляю вверх и сравниваю с нормальным приближением. По доступным размерам A и B отдельно рассчитываю обнаружимый MDE для каждого p0 при мощности 80%, учитывая отношение размеров групп.

Для симуляций беру n из основного сценария: p0=0.5, MDE=1 п.п., мощность 80%. Числа покупок генерирую независимо через биномиальное распределение.

| Проверка | Параметры |
|---|---|
| Синтетический A/A | pA=pB=0.5; 5000 повторений; seed=42 |
| Синтетический A/B | pA=0.5, pB=0.5+delta; 5000 повторений на эффект; seed=43 |
| Эффекты A/B, п.п. | 0; 0.25; 0.5; 0.75; 1; 1.25; 1.5; 2 |

Одна функция z-теста применяется в симуляциях и реальном анализе: группы передаются в порядке [B,A], направление — `larger`. В A/A оцениваю частоту ложных срабатываний, в A/B — эмпирическую мощность и её согласованность с аналитическим расчётом. Для обеих частот строю 95% интервалы Wilson, которые показывают неопределённость симуляций.

Реальный эксперимент анализирую на всех валидных клиентах. Плановый n используется для синтетических проверок.

## Оценка эффекта

Для основного решения использую односторонний p-value при alpha=0.05 и нижнюю одностороннюю 95% score-границу B−A. Границу получаю как нижний конец двухстороннего интервала с alpha=0.10. Отдельно рассчитываю двусторонний 95% score-ДИ с alpha=0.05 для оценки величины эффекта.

В `confint_proportions_2indep` группа B идёт первой; параметры — `compare="diff"`, `method="score"`, `correction=False`. Согласованность score-теста при нулевой разнице, pooled z-теста и нижней односторонней границы проверяю на искусственных примерах и реальных данных.

SRM проверяю критерием χ² относительно предполагаемого 50/50. Исходный план распределения не подтверждён протоколом, поэтому SRM здесь служит диагностикой размеров групп.

## Будущий запуск

Учебное окно покупки — 24 часа после включения клиента. SMS отправляется группе B в начале окна; для контроля задаётся такое же начало наблюдения. В текущем CSV анализируется готовый target за исходный неизвестный период.

Остановка — после набора рассчитанной выборки и полного окна последнего участника. Промежуточный p-value это правило не меняет. Срок набора зависит от потока подходящих уникальных клиентов.

Клиент остаётся в назначенной группе независимо от доставки SMS — intention-to-treat. В текущем анализе сохраняются исходные группы из файла.

Защитная метрика — доля отписавшихся от SMS в каждой исходной группе за одинаковое окно. Допустимый рост отписок нужно согласовать заранее. Диагностическая метрика — доля клиентов B с подтверждённой доставкой среди всех клиентов B; обе метрики в CSV недоступны.

## Решение для команды

По результатам теста оцениваю величину эффекта, его неопределённость и соотношение с плановым эффектом 1 п.п. Основной тест проверяет рост относительно нуля. Для решения о массовой рассылке дополнительно нужны стоимость коммуникации, дополнительная маржа на покупателя, отписки, доставка и критерии отбора будущей аудитории.
